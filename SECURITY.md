# Security Policy

## Supported versions
Se prioriza la rama activa de desarrollo y `main`.

## Reportar vulnerabilidades
Si encuentras una vulnerabilidad:
1. No la publiques en un issue abierto.
2. Reporta detalles mínimos reproducibles al mantenedor por canal privado de GitHub.
3. Incluye impacto, evidencia y pasos de reproducción.

## Alcance
- Dependencias Python
- Flujos CI/CD
- Manejo de datos y salidas generadas

## Divulgación responsable
Se agradece divulgación coordinada; no se garantizan SLA de respuesta o parcheo.
