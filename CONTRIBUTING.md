# Contributing / Cómo contribuir

## Requisitos
- Python 3.12
- Instalar dependencias: `pip install -r requirements.txt`

## Flujo recomendado
1. Haz fork o crea una rama desde `main`.
2. Implementa cambios pequeños y enfocados.
3. Ejecuta:
   - `ruff check .`
   - `ruff format --check .`
   - `pytest -v`
4. Actualiza documentación si el comportamiento cambió.
5. Abre un Pull Request usando la plantilla.

## Buenas prácticas
- Evita incluir secretos o datos sensibles.
- Usa datos oficiales y cita su fuente.
- No presentes resultados exploratorios como predicción determinista de terremotos.

## Reporte de issues
Usa las plantillas de bug/feature y agrega pasos reproducibles.

## Soporte
El mantenimiento es best-effort; no se garantizan tiempos de respuesta.
