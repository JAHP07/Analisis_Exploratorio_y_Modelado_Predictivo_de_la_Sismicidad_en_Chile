# Code of Conduct

Este proyecto adopta un estándar de colaboración respetuosa.

## Nuestro compromiso
Se espera interacción profesional, inclusiva y respetuosa en issues, PRs y discusiones.

## Comportamientos esperados
- Comunicación constructiva.
- Apertura a feedback técnico.
- Respeto por diferencias de experiencia y contexto.

## Comportamientos inaceptables
- Acoso, discriminación o ataques personales.
- Publicación de información privada o sensible sin consentimiento.
- Conducta intimidante o hostil.

## Aplicación
El equipo mantenedor podrá moderar o limitar contribuciones que incumplan estas reglas.

## Reportes
Para incidentes de conducta, usar los canales de contacto del repositorio o abrir un issue privado de seguridad si aplica.
